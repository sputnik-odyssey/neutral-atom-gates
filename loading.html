教材解释：测量、反馈和失锁分别意味着什么？

1. 先得到带符号的频率信息

光电探测器把光信号转成电信号；参考谱线、光学腔或拍频鉴别方案把频差变成可校准的误差信号。在工作点附近，E ≈ Dx，其中 x = νL − νref，D 是鉴频斜率。知道 D 的符号，才能判断频率应升高还是降低。单个吸收峰的强度通常不足以区分峰的两侧，需要相应的鉴频方法。

ℓ = νL − ν₀，r = νref − ν₀，x = ℓ − r
E(x) = A (x/W) / [1+(x/W)²]
Q(x) = 1 / [1+(x/W)²]

本页用上述色散形曲线概括局部鉴频，不把它当作某台 SILC 或真实 PDH 系统的标定曲线。参考缺失时，理想化的 E、Q 均设为零；远离参考时，E 也可能很小。判定锁定还需要确认参考存在、工作点、执行器余量与持续稳定性。

2. 负反馈如何抑制频率漂移

频率偏高时，校正应使频率降低。这里假定执行器的调谐系数为正，以 e = WE/A 表示等效频差，再计算：

u = clip[−σ(KPed + I), −U, U]
dI/dt = KIed，τa da/dt = u − a
ℓ(t) = d(t) + a(t)，ed = e(t − τd)

σ = +1 表示此约定下的负反馈；反转 σ 会把偏差推大。积分提供持续校正，有限行程和延迟则限制环路能力。实际电流/PZT 调谐系数的方向和大小需要标定，不能只照搬控制器的正负号。

3. 为什么增益越大不一定越好？

反馈总是根据有延迟的信息动作。增益过大、延迟较长时，控制器可能在频率已越过目标后仍向原方向校正，引起振荡甚至失锁。行程用尽时，即使仍有误差信号，也无法提供所需校正。本页在饱和时抑制继续向同方向积分；参考缺失或强度低于阈值时冻结积分并保持命令。

这些保护和“锁定”指示均为本页规则。真实 SILC 的滤波器、锁定获取和自动重锁功能更复杂；本模型没有重建其固件，也没有模拟自动扫描重锁。

4. 锁到参考与原子捕获是两个判断

环路可以把 x 压到较小，却不能仅靠同一个误差信号发现参考本身的频率偏差。点击“参考频率偏移”，会看到激光相对参考重新稳定，但 ℓ 仍偏离零；两条冷却支路因而偏离原先的最佳失谐，原子可能不能通过接收窗口。

反过来，短暂偏离锁定判据时，原子也未必立即损失。结果取决于它实际经历的频率、入射时刻和作用时间。本页逐段传播 z(t)、v(t) 与横向轨迹，并沿途读取完整 ℓ(t)，包括传播期间遇到的频率突跳。

教材解释：为什么失谐、速度与磁场必须一起看？

1. 塞曼减速器维持散射条件

取原子沿 +z 运动、减速光沿 −z 传播，光在原子参考系中的频率比实验室中高 v/λ。对所选 σ 跃迁，磁场使共振频率改变 μBB/h。因此本页采用：

d(z,v) = ΔZS + v/λ − (μB/h)Beff(z)
R(d) = (Γ/2) s / [1+s+(2d/γ)²]
Fz = −(h/λ) R(d)，γ = Γ/(2π)

每次吸收反向光子给原子反向动量。自发发射的平均动量在此近似中取零。原子慢下来后，多普勒频移减小；设计合适的空间磁场可以使原子持续处在可散射的速度区间。只有初始速度落在动态接纳范围内、且在有限长度内得到足够减速的原子，才会通过所选速度窗口。

磁场本身不提供本模型中的减速力；关掉光，单凭这个 B(z) 不会产生这里计算的辐射减速。失谐过大时散射太弱；初速过高时可能错过共振或来不及减速；过强减速也可能使原子在出口前停下。故“更红”“更大磁场”或“更慢初速”都不是普遍的优化方向。

2. 2D MOT 同时需要阻尼和恢复力

先看 x 方向。原子向 +x 运动时，来自 −x 的红失谐光更接近共振，产生反向力，这构成速度阻尼。原子偏离中心时，磁场梯度改变两种圆偏振分量的共振条件；配合选定偏振，使指向中心的光力更强，形成位置恢复力。y 方向有另一对光束。

d±x = ΔMOT ∓ vx/λ ∓ (μB/h)bx
qi = si/[1+(2di/γ)²]
Fx = (h/λ)(Γ/2)(q+x−q−x)/(1+Σiqi)

Σ 对四束光求和，y 方向使用相同形式。小位移、小速度下可写成 Fx ≈ −αvx −κx。红失谐和正确偏振、梯度使 α、κ 为正；没有梯度时仍可冷却速度，但不能把任意位置都拉回中心。点击“MOT 无梯度”即可看到：横向速度可能已很低，原子却仍错过出口孔。

2D MOT 对束轴以外的两个方向施加约束；原子沿轴向离开形成束流。轴向越快，驻留时间 LMOT/vz 越短。即使力方向正确，横向初速过高或入射位置过偏，也可能在冷却完成前离开有效区域。

03 / 概念解释

“连续”描述的是整个运行流程

局部步骤仍然可以是脉冲式的

装载、成像、搬运通常有自己的时间窗口。只要补给与存储有适当的空间和时间安排，就可以重复执行这些窗口，并在更新局部原子时保留其余原子。连续运行不要求每束激光始终开启。

保护已有原子是核心条件

冷却和成像需要散射光子，而存储量子态需要降低不受控的环境耦合。不同实验可以利用空间隔离、光屏蔽、态选择等手段解决这项冲突。不能仅凭“仍有很多原子”就判断相干性没有受损。

补充物质资源，不等于修复量子信息

新原子可以被初始化为已知态，随后参与新的计算指令；但旧原子丢失时所携带的未知量子信息不能靠换一个原子直接找回。要维持逻辑信息，还需要相应的编码、损失检测与纠错流程。
