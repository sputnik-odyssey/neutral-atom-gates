FROM ATOMS TO COMPUTATION

从原子实验到可编程计算

控制一个原子的能级，并不自动构成计算。要把实验变成计算机，需要先规定：信息由什么物理状态表示，允许执行哪些操作，操作的顺序怎样由程序指定，以及测量结果如何回答原来的问题。中性原子平台提供这些步骤的物理实现；量子算法规定如何组织这些步骤。

这里的“可以被计算”主要指实验过程可以被建模、编程，并产生有明确含义的计算结果。它包含两种方向：用计算机预测实验的演化，以及让实验装置执行计算。前者是数值模拟，后者是量子计算。只有当输入、操作和输出之间的关系被明确建立，实验才成为可使用的计算过程。

1. 先建立物理状态与信息之间的对应

例如，用两个可区分且寿命足够长的原子能级表示 |0⟩ 与 |1⟩。光镊中的原子位置给出比特编号；初始化把系统制备为已知状态；激光或微波改变状态；最终的荧光成像把编码态转换成经典读数。|0⟩ 与 |1⟩ 是信息标签，它们对应哪个具体能级取决于所选原子和编码方案。

2. 单比特门与双比特门为什么能组成算法？

从物理学看，门是控制哈密顿量在指定时间内产生的演化；从计算机科学看，门是具有明确数学作用的基本指令。单比特门改变一个比特的振幅与相对相位，双比特纠缠门则把两个比特的演化关联起来。仅有彼此独立的单比特门，不能从乘积态制备一般的多比特纠缠态。

任意单比特旋转与 CZ 这样的纠缠门可以组成通用量子门集：把它们作用在不同的比特上并按顺序组合，可以将任意有限比特酉操作逼近到所需精度。实际程序通常只使用一组固定门；例如 H、T 和 CNOT 构成常用的近似通用门集。这并不表示每个任务都能高效完成，所需比特数、门数、精度和误差仍决定程序是否实用。

还必须有测量与经典处理。量子门主要负责相干演化；一次测量按概率产生一个结果，重复实验才能估计概率或期望值。程序不能在一次测量中读出全部叠加分量，也不能仅靠“同时存在很多状态”就得到所有候选答案。

3. 一个最小例子：把条件相位变成逻辑异或

CZ 只给 |11⟩ 增加负号。如果直接测量计算基，这个相位变化看不出来。在目标比特上先后各施加一个 H 门，就把条件相位转化为条件翻转：

CNOT = (I ⊗ H) CZ (I ⊗ H)
|a,b⟩ → |a, a ⊕ b⟩，a,b ∈ {0,1}

例如，输入 |10⟩ 得到 |11⟩，输入 |11⟩ 得到 |10⟩。控制原子的逻辑值为 1 时，目标原子翻转；最终测量的第二位就是两个输入的异或。对基态输入，这个例子只实现一个普通逻辑功能，没有量子加速；对叠加态输入，同一线性操作还可以产生纠缠。它说明了物理相位、门的组合和可读出的计算结果如何衔接。

4. 如何用这些指令研究一个物理课题？

以估计两个自旋系统的基态能量为例。先把目标问题写成可测量算符的组合，例如 Hproblem = J Z₁Z₂ + h(X₁ + X₂)，其中 J、h 是模型参数，X、Z 是泡利算符。这里的目标哈密顿量描述待研究的问题，不必等于原子硬件天然的哈密顿量。

  1. 编码问题。把两个自旋映射到两个原子量子比特，明确需要估计 J⟨Z₁Z₂⟩ + h(⟨X₁⟩ + ⟨X₂⟩)。
  2. 设计并编译电路。选择包含单比特旋转和纠缠门的参数化制备电路，将每个门转换为设备支持的脉冲。门在数学上属于算法，在实验中由控制场实现。
  3. 制备与测量。执行电路并重复采样。计算基测量可估计 ⟨Z₁Z₂⟩；测量前施加 H 可把 X 测量转换为 Z 测量。
  4. 还原目标量。把测得 0、1 分别记为 +1、−1，统计相应乘积和均值，再按 J、h 加权，得到能量估计。
  5. 经典反馈。经典优化器调整电路参数并重复上述过程，寻找更低的能量。这是变分量子算法的基本结构；是否接近基态，还取决于制备电路的表达能力、优化结果和实验误差。

这一任务的输出是能量估计及其不确定度，而不是一张包含全部振幅的波函数表。类似地，材料中的关联函数、量子动力学的观测量或组合问题中的候选解，也需要各自明确的编码、演化与读出方案。一个两比特例子可以轻易用经典计算机求解，它的作用是说明流程，不是证明量子优势。

5. 可编程、可计算与有实际优势，是三个不同问题

有稳定的编码、可控门和读出，说明装置具备可编程计算的基本要素；给定有限规模、有限精度的模型，可以在经典计算机上数值模拟，但资源开销可能很大；对某个课题能否优于现有经典方法，则是另外需要论证的问题。量子计算通常讨论的是计算资源与效率的改变，并不意味着能够解决图灵意义上的不可计算问题。

本网站用小规模数值模型计算原子的演化，是“用经典计算理解实验”的例子。真实中性原子处理器执行编译后的脉冲序列、用测量回答目标问题，才是“让原子参与计算”。门保真度决定指令是否足够准确，响应理论则帮助判断哪些噪声会妨碍这些指令。后续各章分别解释这些环节。

进一步阅读：Barenco 等：通用门的分解；Peruzzo 等：变分本征值求解器。本章两自旋例子用于解释计算流程。

TWO-QUBIT GATES & ENTANGLEMENT

双比特门与量子纠缠

两个量子比特的计算基为 |00⟩、|01⟩、|10⟩、|11⟩，一般双比特门由 4 × 4 酉矩阵描述。某些双比特门能把乘积态变成纠缠态：这样的联合状态无法写成两个独立单比特态的乘积。

CNOT 的规则是：第一个比特为 1 时，翻转第二个比特；否则保持不变。这条规则线性地作用于叠加态的每个分量，过程中不需要测量控制比特。

FIDELITY & PHYSICAL ERRORS

态保真度与门保真度

理想门 U 给出确定的酉演化。实际硬件存在控制偏差、退相干和泄漏，输出通常用密度矩阵 ρ 表示。当理想目标是纯态 |ψ⟩ 时，态保真度定义为 F = ⟨ψ|ρ|ψ⟩。F = 1 表示实际输出与目标完全一致。

计算基概率与相干项

退相干对贝尔态的影响

以贝尔态 |Φ⁺⟩ = (|00⟩ + |11⟩)/√2 为目标，逐渐擦除两个分量间的相干性。

示意噪声模型：ρ = ½(|00⟩⟨00| + |11⟩⟨11|) + η/2(|00⟩⟨11| + |11⟩⟨00|)。仅演示这一特定模型，并非所有门误差。

推论 01

控制偏差 → 状态偏离

使输出偏离目标态的误差会降低态保真度；脉冲角度或相位不准可能造成这种偏离；因此控制误差可能降低保真度。

推论 02

概率正确 ≠ 量子态正确

量子态还包含相干信息；退相干可以保留计算基测量概率而破坏相干项；因此仅核对这些概率不足以判断态是否正确。

推论 03

一个输入正确 ≠ 整个门正确

一个门应对所有输入正确作用；Z 门与恒等操作对 |0⟩ 的作用相同，对 |+⟩ 却不同；因此单一输入的测试不足以评价整个门。

态保真度、门保真度和测量误差，如何区分？

态保真度比较一个实际输出与目标态。平均门保真度则把实际操作与理想操作对纯态输入的输出保真度，按均匀（Haar）分布平均，评价整个操作。

态制备和测量误差（SPAM）会影响实验读数；它们需要与门操作本身的误差区分。测量的随机性本身是量子理论的正常预测，并不等于门发生了错误。

若其他条件相当，操作持续更久、暴露于噪声更长，通常更容易积累误差。双比特门在许多平台上更复杂，但“保真度必然更低”不是数学定理。

INSIDE THE NEUTRAL-ATOM EXPERIMENT

中性原子平台的门操作

下面选用一种具体路线：以光镊囚禁的 ⁸⁷Rb 原子为载体，用两个基态超精细能级编码，再用里德堡态作为双比特门的辅助能级。其他原子种类和编码方式也存在，不必沿用同一套控制方案。

A

光镊囚禁与原子排列

强聚焦、远失谐的光通过光偶极势囚禁单个原子，并可排列或搬运它们。

两束相干光的频率差匹配编码态间的跃迁频率，经远失谐中间态形成有效耦合。

TWO-QUBIT GATE ERRORS

双比特门的误差与保真度

本节研究 π–2π–π 里德堡阻塞门偏离理想 CZ 操作的过程。对每个原子保留 |0⟩、|1⟩、|r⟩ 和其他态 |ℓ⟩ 四个状态，联合系统共有十六个基态。激光驱动 |1⟩ ↔ |r⟩，相互作用使 |rr⟩ 产生能量位移 V。门结束后施加理想的 Z ⊗ Z 相位补偿。

下列演示允许分别改变脉冲面积误差 ε、纯退相干强度 g、阻塞强度 b、自发衰变强度 a 和激光失谐 δ。自发衰变包含回到 |0⟩、回到 |1⟩ 和进入其他态 |ℓ⟩ 的三个独立有效分支；可以在固定总衰变率下改变分支比例。保真度计算同时包含逻辑态改变、相干性损失与编码子空间外泄漏，不进行后选择或归一化补偿。

b = 0 表示无相互作用。b 较大时，双里德堡激发被抑制；有限 b 仍可能产生条件相位误差。

Δ 为激光频率与跃迁频率之差。此处失谐在所有重复实验中固定；随机频率漂移或相位噪声未包含在该参数中。

自发衰变的三个有效分支

总衰变率 Γ 保持不变，三个分支率分别为 Γβ₀、Γβ₁、Γβℓ，且 β₀ + β₁ + βℓ = 1。调整一个滑块后，另两个比例按原来的相对比例重新分配，使总和始终为 100%。若另两个比例原先均为零，则等分剩余比例。

回到编码子空间，但可能把原来的逻辑 1 改为 0；此后 |0⟩ 不再被里德堡光激发。

原子回到被驱动的编码态，但辐射仍可破坏相干性，后续脉冲也可能再次激发它。

|ℓ⟩ 为吸收态，不受后续脉冲驱动、不与 |r⟩ 相互作用，也不返回编码态。它代表本模型中不可恢复的其他态泄漏。

1. 激光脉冲面积误差

理想 π 脉冲应完成 |1⟩ 与 |r⟩ 之间的完全转移；理想 2π 脉冲应使参与跃迁的分量返回，并获得相应相位。当脉冲面积存在误差时，转移通常不完全，门结束后可能残留里德堡布居。连续的相干误差还可能彼此抵消或叠加，因此总误差不能直接写成各脉冲误差概率之和。

2. 驱动过程中的纯退相干

本模型中的退相干作用于每个原子的基态—里德堡态相干项，而不是直接修改最终保真度。纯退相干本身不改变无驱动系统的布居，但在脉冲驱动过程中会降低相干转移的完整性，因此也可能使门结束后的泄漏增加。这与自发衰变造成的能量弛豫不同；两者同时存在时，基态—里德堡态相干衰减率为 γφ + Γ/2。

3. 不完全里德堡阻塞

当 b 有限时，|r1⟩ 与 |rr⟩ 之间的跃迁只发生有限失谐，双激发不再严格为零。同时，即使门结束后的双激发布居很小，非共振耦合也可能积累额外相位，降低门保真度。矩形脉冲会产生相干振荡，因而有限区间内的误差曲线不必严格单调。

4. 里德堡态自发衰变与纯退相干

自发辐射使原子与未观测的辐射场关联，产生不可逆的能量弛豫。本模型采用 Jₖ,ⱼ = √(Γβₖ)|k⟩⟨r|ⱼ，k ∈ {0,1,ℓ}，描述三个互不相干的辐射分支。即使衰变使原子重新进入编码态，辐射携带的信息也可能破坏叠加态中的相干关系，因此不能把“回到 |1⟩”等同于“门操作正确”。

关闭驱动后，纯退相干不改变 ρᵣᵣ，而自发衰变使其按 e−Γt 衰减。对于 |1⟩ 与 |r⟩ 构成的有效二能级子系统，1/T₂ = Γ/2 + γφ，T₁ = 1/Γ。该 T₂ 指基态—里德堡态相干时间，不是编码态 |0⟩ 与 |1⟩ 的存储相干时间。

分支比例与后续驱动的共同作用

回到 |0⟩ 的分支会使原子退出后续 |1⟩ ↔ |r⟩ 驱动，并可能留下计算基逻辑错误；回到 |1⟩ 的原子则可以再次被激发。进入 |ℓ⟩ 的原子不再参与计算，但另一个原子仍可继续演化。因此，其他态泄漏、门结束时的里德堡布居和逻辑改变应分别统计。

在固定 Γ 下，改变 βₖ 不改变无驱动里德堡布居的衰减律，也不改变 |ρ₁ᵣ| 的总衰减率 Γ/2 + γφ；它改变的是衰变后布居的去向。在有驱动的门序列中，这种差别又影响后续激发、相位和最终输出。表格中的比较采用同一组控制参数，不将概率损失直接等同于全部门误差。

5. 固定激光失谐与脉冲面积误差

脉冲面积误差改变共振驱动的转角。失谐则在哈密顿量中引入额外的对角项，使旋转轴偏离共振方向，并使广义拉比频率变为 √(Ω² + Δ²)。在基顺序 (|1⟩, |r⟩) 下，去掉整体相位后的哈密顿量为 ℏ(Ωσₓ + Δσz)/2，旋转轴沿 (Ω, 0, Δ)。因此，即使保持原来的脉冲面积，失谐仍可使布居转移不完全并引入相位偏差。

固定且已知的失谐属于相干控制误差：在本模型中，它本身不产生不可逆的相干幅度衰减。若失谐在不同实验或演化过程中随机波动，则可能在平均后表现为退相干；这与这里的恒定 δ 参数不同。复合脉冲、频率校准或重新优化控制可以用于补偿相干误差，但不等同于消除自发辐射产生的不可逆信息损失。

噪声功率谱与保真度响应

同样的噪声总功率，分布在不同频段时，可以造成不同的门误差。保真度响应理论把两个问题分开：功率谱 S(f) 描述噪声的频率分布，响应函数 I(f) 描述给定门协议和初态对各频率的敏感程度。

两种 CZ 协议：顺序寻址与全局相位调制

顺序门依次对控制、目标、控制原子施加 π、2π、π 脉冲，总时长为 4π/Ω。相位调制门则同时驱动两个原子，在保持每个原子驱动幅度 Ω 不变的同时改变相位 φ(t)。在无限阻塞下，|11⟩ 与亮态 (|1r⟩+|r1⟩)/√2 的耦合比单原子的耦合强 √2 倍；合适的相位轨迹使各计算基输入都返回编码空间，并留下所需条件相位。末端的局域 Z 相位补偿后，两者都实现 CZ。

本页采用论文引用的 Evered 等人正弦参数化：φ(t) = A cos(ωt − φ₀)。在本页理想模型中重新校准后，A = 0.704970 rad，ω/Ω = 1.042828，φ₀ = −0.727319 rad，ΩT = 7.642815。完整数值参数保存在计算模块中；下方同时报告无噪声闭合误差。这些是本页的理想模型校准值，不是对原实验标定值的转录。

文献通常把这类波形称为“时间最优门”，更严格地说，正弦参数化实现的是近时间最优协议；严格数值最短门约为 ΩT = 7.612。在相同单原子峰值 Ω 下，本页相位调制门比 4π 顺序门短约 39%。这里比较的是相同单原子峰值驱动和相同激光噪声，并未固定总光能或将两种协议强行拉伸到相同门时长。

为何不同频段的敏感性不同？

两种协议的末端操作都是 CZ，但门过程中的 U₀(t) 不同。顺序门交替驱动两个原子，存在分段的激发与等待；全局门同时驱动两个原子，并连续转动驱动相位，单激发与亮态也具有不同的有效耦合。于是 OH(t) = U₀†(t)O(t)U₀(t) 的时间变化不同，式 (9) 中不同时间的关联及其抵消方式也不同。

在低频极限，cos[2πf(t−τ)] 接近 1，响应主要反映整个门对近静态扰动的累积敏感性。频率升高后，余弦权重使不同时间段相互抵消或增强，形成峰、谷和零点。连续相位调制与较短时长会改变这些结构，但不能仅由“门更短”推出所有频率的响应都更小。

例如，在默认 Ω/(2π) = 3 MHz、完整四维 Haar 平均下，近直流强度噪声对相位调制门的影响较小；把同功率的窄带强度噪声移到约 1.5 MHz，顺序门的贡献反而较小。两个对照按钮可以检验这一排序变化。实际判断应比较 ∫S(f)I(f)df，而不是只比较门时长、响应的最高点或某一个频率的值。

频率噪声在两个原子上采用同一个随机失谐，强度噪声也作为同一激光的共同相对波动；ν 与 I 两类噪声互不相关。若两个原子的激光波动彼此独立，必须改用对应的多个噪声算符及谱，不能直接沿用本页的共同噪声结果。

公式 (8) 的含义与限制

保持 ∫S df 不变而移动谱峰，可以区分“噪声总功率”与“噪声落在哪些频段”。响应函数由门协议、门速度、噪声耦合算符及输入范围决定；它不随当前噪声 RMS 改变。本模型中，增大 RMS 只提高 S(f)，不改变 I(f)。

两个独立噪声的领先阶贡献可以相加；存在互相关时，还需要交叉谱及相应响应项。若误差不再很小，或者关注高阶效应，不能把式 (8) 的结果当作精确失保真度，应与完整的噪声演化核对。下面的数值只包含已勾选的两类激光噪声，不包含上一节的衰变、有限阻塞和读出误差。

先把哈密顿量扰动写为 δH(t)/ℏ = h(t)O(t)。h(t) 是随时间波动的实随机幅度，O(t) 规定它通过哪个物理量耦合到原子。频率噪声与相对强度噪声具有不同的 O(t)，因此也有不同的响应函数。

U₀(t) 是无噪声的理想演化。海森堡图景算符 OH(t) 把噪声耦合变换到随理想演化旋转的参考系。连通关联定义为 ⟨AB⟩c = ⟨AB⟩ − ⟨A⟩⟨B⟩：减去均值乘积，才能排除只产生整体相位、并不降低保真度的部分。

噪声算符、单边谱约定、单位与数值验证

单边谱。对零均值实平稳噪声 h(t)，采用 ⟨h(t)h(τ)⟩ = ∫₀∞S(f)cos[2πf(t−τ)]df，所以 ⟨h²⟩ = ∫S df。只有 f ≥ 0，不再额外乘 2。窄带、低通与白噪声均为本页设置的带限谱，不是论文的实测数据。

频率噪声。hν = δν，使用 MHz；对应的哈密顿量扰动为 δH/ℏ = −2πδν(nᵣ,c+nᵣ,t)，故 Oν = −2π(nᵣ,c+nᵣ,t)。Sν 的单位为 MHz²/MHz，Iν 的单位为 μs²，∫SνIνdf 无量纲。

相对强度噪声。hI = δI/I 为无量纲分数。此处假设该有效驱动满足 Ω ∝ √I，弱噪声下 δΩ/Ω ≈ hI/2，所以 OI(t) = Hdrive(t)/(2ℏ)，并不是把本页前节的幅度误差 ε 原样当作相对强度噪声。SI 的单位为 MHz⁻¹，II 无量纲。文献中的 RIN 若以 dBc/Hz 给出，需要先还原为线性 PSD 并统一频率单位。

理想门与平均。采用无限阻塞投影后的八维空间，排除 |rr⟩，无衰变、无光移、无 AOM 上升下降沿。顺序门依次施加 π、2π、π 脉冲，相位调制门同时驱动两个原子；末端的理想单比特相位补偿不改变响应。完整四维 Haar、三维对称 Haar 与单个 |++⟩ 使用不同的输入投影；本页不把它们当作相同的保真度指标。

数值计算。顺序门在矩形脉冲内解析计算，相位调制门在单激发及对称亮态块内用四阶 Runge–Kutta 积分，采用 768 个时间中点和 401 个频率点。功率谱与贡献积分使用梯形法，时间响应使用中点积分。绝对值小于 10⁻¹² 的读数显示为“≈ 0”，以避免把浮点舍入误差解释为负响应。已通过直接时间双重求和、单频随机相位噪声的完整演化、单位缩放、功率缩放和网格收敛检查。

对应论文。本节实现公式 (8)、(9)及附录式 (G13)，并使用式 (12)–(14)的理想全局驱动模型。相位波形按论文引用的正弦参数化，在本地理想模型中校准；未加入实验 AOM 上升下降沿、自光移、有限阻塞或 SSB 读出，不声称逐点复现论文实验曲线。参数化来源为 Evered 等，Nature 622, 268 (2023)，Methods 式 (1)；严格时间最优结果见 Jandura 与 Pupillo (2022)。参考 Tsai、Sun 等，arXiv:2407.20184v2，第 III 节与附录 G。
