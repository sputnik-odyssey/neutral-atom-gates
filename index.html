SINGLE-QUBIT GATES

单比特态与单比特门

经典比特取值为 0 或 1。量子比特可以处于叠加态 |ψ⟩ = α|0⟩ + β|1⟩，其中 |α|² + |β|² = 1。测量概率由振幅的模平方决定，而分量之间的相对相位会影响后续干涉。

单比特门用一个 2 × 2 的酉矩阵 U 表示：|ψ′⟩ = U|ψ⟩。它可以改变振幅与相位，并且可逆。在忽略整体相位后，其作用可以表示为布洛赫球上的旋转。

TWO-QUBIT GATES & ENTANGLEMENT

双比特门与量子纠缠

两个量子比特的计算基为 |00⟩、|01⟩、|10⟩、|11⟩，一般双比特门由 4 × 4 酉矩阵描述。某些双比特门能把乘积态变成纠缠态：这样的联合状态无法写成两个独立单比特态的乘积。

CNOT 的规则是：第一个比特为 1 时，翻转第二个比特；否则保持不变。这条规则线性地作用于叠加态的每个分量，过程中不需要测量控制比特。

FIDELITY & PHYSICAL ERRORS

态保真度与门保真度

理想门 U 给出确定的酉演化。实际硬件存在控制偏差、退相干和泄漏，输出通常用密度矩阵 ρ 表示。当理想目标是纯态 |ψ⟩ 时，态保真度定义为 F = ⟨ψ|ρ|ψ⟩。F = 1 表示实际输出与目标完全一致。

推论 01

控制偏差 → 状态偏离

使输出偏离目标态的误差会降低态保真度；脉冲角度或相位不准可能造成这种偏离；因此控制误差可能降低保真度。

推论 02

概率正确 ≠ 量子态正确

量子态还包含相干信息；退相干可以保留计算基测量概率而破坏相干项；因此仅核对这些概率不足以判断态是否正确。

推论 03

一个输入正确 ≠ 整个门正确

一个门应对所有输入正确作用；Z 门与恒等操作对 |0⟩ 的作用相同，对 |+⟩ 却不同；因此单一输入的测试不足以评价整个门。

态保真度、门保真度和测量误差，如何区分？

态保真度比较一个实际输出与目标态。平均门保真度则把实际操作与理想操作对纯态输入的输出保真度，按均匀（Haar）分布平均，评价整个操作。

态制备和测量误差（SPAM）会影响实验读数；它们需要与门操作本身的误差区分。测量的随机性本身是量子理论的正常预测，并不等于门发生了错误。

若其他条件相当，操作持续更久、暴露于噪声更长，通常更容易积累误差。双比特门在许多平台上更复杂，但“保真度必然更低”不是数学定理。

INSIDE THE NEUTRAL-ATOM EXPERIMENT

中性原子平台的门操作

下面选用一种具体路线：以光镊囚禁的 ⁸⁷Rb 原子为载体，用两个基态超精细能级编码，再用里德堡态作为双比特门的辅助能级。其他原子种类和编码方式也存在，不必沿用同一套控制方案。

A

强聚焦、远失谐的光通过光偶极势囚禁单个原子，并可排列或搬运它们。

两束相干光的频率差匹配编码态间的跃迁频率，经远失谐中间态形成有效耦合。

TWO-QUBIT GATE ERRORS

双比特门的误差与保真度

本节研究 π–2π–π 里德堡阻塞门偏离理想 CZ 操作的过程。对每个原子保留 |0⟩、|1⟩、|r⟩ 三个能级，联合系统共有九个基态。激光驱动 |1⟩ ↔ |r⟩，相互作用使 |rr⟩ 产生能量位移 V。门结束后施加理想的 Z ⊗ Z 相位补偿。

下列演示允许分别改变脉冲面积误差 ε、纯退相干强度 g、阻塞强度 b、自发衰变强度 a 和激光失谐 δ。自发衰变采用有效闭合通道 |r⟩ → |1⟩，用于说明能量弛豫的作用，不代表真实铷原子的完整衰变分支。所有保真度均将门结束后残留在里德堡态中的概率计为误差，不进行后选择或归一化补偿。

1. 激光脉冲面积误差

理想 π 脉冲应完成 |1⟩ 与 |r⟩ 之间的完全转移；理想 2π 脉冲应使参与跃迁的分量返回，并获得相应相位。当脉冲面积存在误差时，转移通常不完全，门结束后可能残留里德堡布居。连续的相干误差还可能彼此抵消或叠加，因此总误差不能直接写成各脉冲误差概率之和。

2. 驱动过程中的纯退相干

本模型中的退相干作用于每个原子的基态—里德堡态相干项，而不是直接修改最终保真度。纯退相干本身不改变无驱动系统的布居，但在脉冲驱动过程中会降低相干转移的完整性，因此也可能使门结束后的泄漏增加。这与自发衰变造成的能量弛豫不同；两者同时存在时，基态—里德堡态相干衰减率为 γφ + Γ/2。

3. 不完全里德堡阻塞

当 b 有限时，|r1⟩ 与 |rr⟩ 之间的跃迁只发生有限失谐，双激发不再严格为零。同时，即使门结束后的双激发布居很小，非共振耦合也可能积累额外相位，降低门保真度。矩形脉冲会产生相干振荡，因而有限区间内的误差曲线不必严格单调。

4. 里德堡态自发衰变与纯退相干

自发辐射使原子与未观测的辐射场关联，产生不可逆的能量弛豫。本模型采用 Jⱼ = √Γ |1⟩⟨r|ⱼ 表示有效闭合回落。即使衰变使原子重新进入编码态，辐射携带的信息也可能破坏叠加态中的相干关系，因此不能把“回到 |1⟩”等同于“门操作正确”。

关闭驱动后，纯退相干不改变 ρᵣᵣ，而自发衰变使其按 e−Γt 衰减。对于 |1⟩ 与 |r⟩ 构成的有效二能级子系统，1/T₂ = Γ/2 + γφ，T₁ = 1/Γ。该 T₂ 指基态—里德堡态相干时间，不是编码态 |0⟩ 与 |1⟩ 的存储相干时间。

5. 固定激光失谐与脉冲面积误差

脉冲面积误差改变共振驱动的转角。失谐则在哈密顿量中引入额外的对角项，使旋转轴偏离共振方向，并使广义拉比频率变为 √(Ω² + Δ²)。在基顺序 (|1⟩, |r⟩) 下，去掉整体相位后的哈密顿量为 ℏ(Ωσₓ + Δσz)/2，旋转轴沿 (Ω, 0, Δ)。因此，即使保持原来的脉冲面积，失谐仍可使布居转移不完全并引入相位偏差。

固定且已知的失谐属于相干控制误差：在本模型中，它本身不产生不可逆的相干幅度衰减。若失谐在不同实验或演化过程中随机波动，则可能在平均后表现为退相干；这与这里的恒定 δ 参数不同。复合脉冲、频率校准或重新优化控制可以用于补偿相干误差，但不等同于消除自发辐射产生的不可逆信息损失。

平均门保真度。令 ℰ 为含理想相位补偿的实际量子通道，U = CZ，P 为四维计算子空间的投影。定义

Favg = ∫ dψ ⟨ψ|U†P ℰ(|ψ⟩⟨ψ|) P U|ψ⟩，

积分遍历计算子空间的全部纯态，采用归一化 Haar 测度。P 仅用于计算与目标态的重叠，不对输出作条件归一化。因此泄漏会降低保真度。本模型相对于 CZ 的 Favg，也等于前后附加理想 H 门后，相对于 CNOT 的平均门保真度。

测试态。测试输入为 |++⟩ = (|00⟩ + |01⟩ + |10⟩ + |11⟩)/2，目标为 |G⟩ = CZ|++⟩。页面单独显示 Ftest = ⟨G|ρout|G⟩，它一般不等于 Favg。由于本模型不耦合不同的逻辑扇区，可利用该结构计算完整通道的平均指标，得到 Favg = (1 − Lavg + 4Ftest)/5。此关系只适用于这里的模型，不能用于任意量子通道或仅凭单一输入评价未知门。

数值方法与范围。每个 π 时长分成 128 步，采用保持完全正性与迹的对称分裂法；相干演化使用含失谐的二能级块解析指数，纯退相干和幅度阻尼使用精确通道。结果保留两位百分数。模型用于说明机制，未包含真实多分支自发衰变与级联、黑体诱导跃迁、多重里德堡能级、原子运动、中间态散射、光束串扰、态制备和测量误差；参数为无量纲示例，不代表某台实验装置。

里德堡门的系统误差分析参见 Zhang 等（2012）；平均门保真度的基本定义参见 Nielsen（2002）。本页采用包含泄漏的计算子空间重叠定义。
