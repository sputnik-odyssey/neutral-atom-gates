# 量子门与中性原子计算

中文交互式物理讲义：从中性原子实验到可编程计算、量子门、保真度、多分支衰变与协议响应比较。

在线访问：https://sputnik-odyssey.github.io/neutral-atom-gates/

## 硬件实验室值班

入口：https://sputnik-odyssey.github.io/neutral-atom-gates/hardware.html

第二款独立像素游戏发生在同一间硬件实验室。玩家领取触发线与功率计，连接时序与相机，调节高斯模式位移，检查抽气支路，设置离散反馈极性，采集泊松参考帧，最后排列装载/初始化/π 脉冲/成像时序。设备实时就绪状态与历史工单分别记录；修改曝光或光路后参考帧会失效。

`hardware-model.mjs` 是独立的简化设备模型：高斯重叠 η=exp[−(x²+y²)/16]、指数抽气、与压力成正比的碰撞率、线性离散反馈、条件于原子存在的泊松计数、含失谐的两能级转移。最终有效成功率为原子存留率×转移概率×目标亮态的正确读出率。它不是完整硬件误差预算，数值阈值与抽气时间均为关卡参数。支持自动寻路、键盘、触屏、地图放大、独立本机存档和结局报告。

## 像素游戏

入口：https://sputnik-odyssey.github.io/neutral-atom-gates/game.html

独立的像素实验室提供六个任务：初始化与编码、H–Z–H 干涉、以 H/CZ 编译贝尔态、校准四类 CZ 误差、固定总衰变率比较末态分支、按同一强度噪声谱选择 CZ 协议。支持地图点击自动寻路、WASD/方向键、E 操作和触屏方向键；关卡逐步解锁，完成记录只保存在本机 localStorage。音效默认关闭。

`game-physics.mjs` 提供纯态门运算，第四/五关复用 `branching.mjs`，第六关使用 `frt-worker.mjs` 的两种响应。成绩不依赖随机测量频数；64 次采样只展示 Born 统计。游戏中的像素位置与四项维修数属于交互规则，不是实验资源估计。

## 当前数值模型

`branching.mjs`：每原子采用 0、1、r、ℓ 四个状态，联合维数 16；计算基索引为 0、1、4、5。ℓ 不受驱动且不返回其他态。相互作用只作用于 rr。

哈密顿量：H/ℏ = Ω₀(1+ε)(|1⟩⟨r|ⱼ+h.c.)/2 − Δ(nᵣ,c+nᵣ,t) + bΩ₀|rr⟩⟨rr|。

三个脉冲时长 π/Ω₀、2π/Ω₀、π/Ω₀；门时长 t_g=4π/Ω₀，δ=Δ/Ω₀。两个原子的独立通道为 Lφ,ⱼ=√(2γφ)nᵣ,ⱼ 和 Jₖ,ⱼ=√(Γβₖ)|k⟩⟨r|ⱼ，k=0,1,ℓ，Σβₖ=1。

每 π 时长 128 步，采用解析酉块、精确多分支 Kraus 通道与纯退相干通道的对称分裂。每条衰变分支独立作用，不能相干叠加跳跃算符。实际完整密度矩阵保持迹为 1。

F_avg=(P_comp+4F_e)/5 使用包含泄漏的 Haar 平均恒等式；F_e 不再用物理测试输入 |++⟩ 的输出保真度代替。计算混合输入给出平均存留率，辅助迹递减映射用于过程重叠，并以所有 16 个逻辑输入算符传播验证。逻辑改变 P_flip 指计算基真值表中的错误，不统计纯相位误差。

辅助映射只保留不发生跃迁和 r→1 跳跃的轨迹。r→0 跳跃会不可逆地改变某个逻辑 1，r→ℓ 跳跃离开计算空间，这些 Kraus 路径对相对于对角 CZ 的迹重叠为零。该结构只用于加速过程重叠计算，不对真实通道后选择或归一化。

主线程计算当前参数，`noise-worker.mjs` 在后台计算扫描和分支对照，旧请求会被丢弃。`noise.mjs` 保留前一版闭合三能级模型及单脉冲解析函数，用于回归核对；生产交互使用 `branching.mjs`。

模型中的其他态是聚合的不可返回状态，未逐态描述真实辐射级联、黑体诱导跃迁、再泵浦、原子运动或实验读出；可调比例不是某个物种的实测分支比。

## 保真度响应模型与协议比较

`frt.mjs` 使用无限阻塞投影后的八维空间，比较顺序 π–2π–π 与全局正弦相位调制的理想 CZ。前者解析计算，后者由 `phase-gate.mjs` 在单激发与亮态的二能级块内做 RK4 积分。全局门采用 Evered 等 Methods 式 (1) 的波形形式，在本页无限阻塞模型中重新校准：A=0.7049699991530635，ω/Ω=1.0428277312172531，φ0=−0.727319497510921，ΩT=7.642814558109514。参数不是原实验标定值；这是文献常称时间最优的近时间最优参数化门，并非严格 ΩT≈7.612 的数值最短波形。`reference_phase_gate.py` 用 NumPy 和独立 RK4/Newton 过程复现校准。频率噪声采用共同耦合 Oν=−2π(nr,c+nr,t)，相对强度噪声采用 OI=Hdrive/(2ℏ)；后者包含 Ω∝√I 的 1/2 系数。两类噪声独立，使用单边谱约定 ∫S df=RMS²，无额外因子 2。时间以 μs、频率以 MHz 表示。所有谱在 0–12 MHz 内归一化，带外设零。

默认 768 个时间中点、401 个频率点；由海森堡图景算符的连通关联计算响应。完整四维 Haar、三维对称 Haar 和单个 |++⟩ 输入分别计算，Haar 平均使用纯态平均公式，不能用混合态协方差替代。频率积分使用梯形法。`frt-worker.mjs` 缓存理想响应，两种协议使用相同单原子峰值拉比频率、相同输入范围和逐点相同的物理频率 PSD；未固定总光能或门时长。谱控件只改变共享谱及两组重叠积分。热图直接双重求和与响应算法独立核对。

本节仅包含弱经典平稳激光噪声的领先阶贡献，不含衰变、有限阻塞、光移、脉冲上升沿或 SSB 读出；相位协议实现论文理想模型的同类正弦参数化波形，不能把所得曲线视为含 AOM、自光移等装置效应的实验响应。低频与半拉比频率强度噪声按钮固定 RMS 与谱宽，展示协议排序的反转。

## 验证

```sh
node --test noise.test.mjs branching.test.mjs frt.test.mjs game.test.mjs hardware.test.mjs
python3 reference_branching.py
```

当前 51 项 Node 测试包含两种门，以及游戏纯态操作、通关阈值与地图可达性。FRT 测试另核对理想门酉性、直接双重积分、16 个随机相位的单频噪声完整 RK4 演化、单位缩放、功率平方律、时间/频率网格收敛、全局门闭合与局域 Z 补偿后的 CZ 条件相位，以及相同谱下的协议排序反转。

独立 Python 参考使用 NumPy，按 RK4 直接传播全部 16 个逻辑输入算符；网站本身不需要 Python。测试核对解析衰变、归一性、旧版闭合极限、逻辑改变、吸收态、通道平均、独立参考与步长收敛。
